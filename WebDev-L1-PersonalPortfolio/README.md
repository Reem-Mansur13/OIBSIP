# Personal Portfolio Website

## Track: Web Development & Designing (Level 1 - Task 2)

### Description
A modern, fully responsive personal portfolio website created to showcase my web development projects, skills, education journey, and contact details.

### Features
- **Hero Section:** Introduction with dynamic profile image and clear CTA.
- **About Me Section:** Brief summary and key personal details.
- **Skills Section:** Interactive progress bars and tech badges.
- **Projects Section:** Showcase of completed projects with filter tabs.
- **Journey Timeline:** Academic history and professional timeline.
- **Testimonials Slider:** Interactive feedback showcase.
- **Contact Form & Direct Links:** Clickable email, phone, and location links with form input validation.
- **Theme Toggle:** Dark/Light mode switcher.

### Tech Stack
- HTML5
- CSS3 (Flexbox, Grid, Glassmorphism design)
- JavaScript (DOM manipulation, smooth scrolling)
